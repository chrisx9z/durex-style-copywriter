# 🌶️ Durex-Style Copywriter (Máy tạo Copy 2 Lớp Ngữ Nghĩa)

Ứng dụng Web tĩnh (Client-side, Zero-dependency) giúp sáng tạo câu chữ quảng cáo tiếng Việt sắc sảo theo phương pháp luận **"Ngữ nghĩa hai lớp" (Dual-Layer Semantics)** — được đúc kết từ thời kỳ hoàng kim của các chiến dịch Durex (Huanshi Interactive 2011–2017).

Công cụ tự động gợi ý: **Công thức viết, Headline, Subhead, Lý do hiệu quả (Bề mặt & Tầng chìm), Chủ thể hình ảnh, Bảng màu và Xuất ảnh Poster mockup chất lượng cao**.

## 🧠 Triết lý cốt lõi: "Ngữ nghĩa hai lớp" là gì?

Khác với quảng cáo thông thường chỉ nói trực diện về sản phẩm hoặc chơi chữ bề mặt vô nghĩa ("dad jokes"), một câu copy phong cách Durex hoạt động đồng thời trên **hai tầng nghĩa**:

1. **Tầng bề mặt**: Một sự kiện nóng, thời tiết, thói quen đời thường, thời khắc đặc biệt — đọc theo nghĩa đen hoàn toàn bình thường, trong sáng và hợp lý.
2. **Tầng chìm**: Thông điệp sâu sắc về giá trị sản phẩm, khát khao hoặc giải pháp thật sự của thương hiệu.

> **Quy tắc 1 bước liên tưởng:**  
> Người đọc phải **TỰ** kết nối hai tầng nghĩa này trong tích tắc. Nếu chỉ cần **1 bước liên tưởng**, câu copy sẽ "bùng nổ" (khiến người xem bật cười hoặc gật gù tâm đắc). Nếu cần từ 2 bước trở lên hoặc phải giải thích ra bằng lời, câu copy coi như thất bại.

## 🎯 8 Công thức Copywriting được tích hợp

| STT | Tên công thức | Bản chất & Cơ chế |
| :---: | :--- | :--- |
| **1** | **Chơi chữ đồng âm / gần âm** | Đổi 1 từ trong thành ngữ, hot-trend bằng từ đồng âm gắn liền với sản phẩm. |
| **2** | **Chơi số** | Biến con số sẵn có của trend (ngày, giờ, phiên bản, giá) thành một ý nghĩa hoàn toàn mới. |
| **3** | **Chiếm dụng thuật ngữ** | Mượn thuật ngữ chuyên ngành (kỹ thuật, y khoa, luật, giao thông) để mô tả sản phẩm theo nghĩa đen. |
| **4** | **Chuyển cảnh / Nhân cách hoá** | Để một vật thể phụ trong bối cảnh tự thuật ở ngôi thứ nhất, ngụ ý hành động của nhân vật chính. |
| **5** | **Tách ghép chữ** | Tách từ ghép thành 2 nghĩa độc lập hoặc sử dụng nghệ thuật nói lái tinh tế trong tiếng Việt. |
| **6** | **Thể lịch / Đối xứng** | Cấu trúc "Nên làm gì / Không nên làm gì" kiểu lịch vạn niên hoặc 2 vế tương phản chan chát. |
| **7** | **Thể thơ ba lớp** | Ba câu ngắn tả cảnh tăng tiến dần, câu cuối bẻ lái ngoạn mục sang thông điệp sản phẩm. |
| **8** | **Kiềm chế ngược** | Giữa lúc khán giả mong chờ một câu đùa cợt, lại nói một câu chân thành, sâu lắng và đắt giá. |

## 🚀 Các tính năng nổi bật (Features)

* **Hỗ trợ 5 nhà cung cấp AI phổ biến:**
  * **OpenRouter (Khuyên dùng)**: Kết nối trực tiếp từ trình duyệt **không lo lỗi CORS**, hỗ trợ đầy đủ `deepseek/deepseek-chat`, `anthropic/claude-3.5-sonnet`, `openai/gpt-4o`, `google/gemini-2.5-flash`...
  * **Google Gemini**: Hỗ trợ REST API Key trực tiếp từ trình duyệt (miễn phí qua Google AI Studio).
  * **Claude (Anthropic)**: Gọi trực tiếp qua browser headers.
  * **OpenAI & DeepSeek**: Hỗ trợ Custom Base URL / Reverse Proxy để bypass CORS.
* **Thanh chọn mức độ táo bạo (Boldness Level):**
  * 🌿 *Tinh tế*: Ẩn dụ kín đáo, trang nhã, phù hợp B2B, ngân hàng, giáo dục.
  * ⚡ *Hóm hỉnh*: Chơi chữ hóm hỉnh, cân bằng, phù hợp F&B, bán lẻ, công nghệ.
  * 🔥 *Táo bạo*: Đậm chất Durex nguyên bản, sắc sảo, gợi mở kích thích trí tưởng tượng.
* **Ý tưởng mẫu 1-Click (Presets):** Cung cấp sẵn các mẫu thực chiến (Cà phê 24h, App tài chính, Đồ ăn đêm mưa, Phòng gym sau Tết, Khóa học tiếng Anh).
* **Mô phỏng Poster thực tế (Poster Mockup Studio):**
  * Chuyển đổi giữa chế độ *Dạng Thẻ chi tiết* và *Mô phỏng Poster*.
  * Tự động áp dụng bảng màu và bố cục tương phản.
  * **Tải Poster ảnh PNG độ nét cao (Native Canvas)**: Tự động căn chữ, ngắt dòng và xuất file ảnh ngay lập tức mà không cần bất kỳ thư viện ngoài nào!
* **Tiện ích copy nhanh:**
  * Nút `📋 Sao chép Text` copy trọn vẹn Headline, Subhead và giải thích.
  * Nút `🎨 Prompt Midjourney / Flux` tự sinh prompt tạo ảnh tối giản chuẩn Durex sang tiếng Anh.
* **Lưu kho yêu thích (Favorites):** Lưu trữ các phương án đắc ý vào `localStorage` để xem lại bất cứ lúc nào.
* **Bảo mật & Tiện dụng:** Tùy chọn nhớ API Key an toàn trong trình duyệt hoặc xóa sạch khi đóng tab.

## 🛠️ Hướng dẫn sử dụng & Cấu hình API Key

1. **Khuyên dùng OpenRouter (Đơn giản nhất, không lo lỗi CORS)**:
   * Đăng ký tài khoản tại [openrouter.ai](https://openrouter.ai/) và tạo một API Key.
   * Chọn nhà cung cấp `OpenRouter`, dán key vào và chọn model tùy thích (mặc định: `deepseek/deepseek-chat`).
2. **Dùng Google Gemini (Miễn phí)**:
   * Lấy API Key miễn phí tại [Google AI Studio](https://aistudio.google.com/).
   * Chọn nhà cung cấp `Google (Gemini)`, dán key và bắt đầu sử dụng.
3. **Nếu muốn dùng OpenAI / DeepSeek trực tiếp từ trình duyệt**:
   * Do chính sách bảo mật mạng (CORS), trình duyệt sẽ chặn request trực tiếp tới `api.openai.com` hoặc `api.deepseek.com`.
   * Bạn có thể mở mục **⚙️ Tùy chọn nâng cao (Custom Base URL / Proxy)** và điền URL proxy cá nhân (Cloudflare Worker hoặc reverse proxy).

### Mẫu Cloudflare Worker CORS Proxy (Tùy chọn)
Nếu bạn muốn tự làm proxy riêng để gọi OpenAI từ web tĩnh, tạo một Worker với mã sau:
```javascript
export default {
  async fetch(request) {
    if (request.method === "OPTIONS") {
      return new Response(null, {
        headers: {
          "Access-Control-Allow-Origin": "*",
          "Access-Control-Allow-Methods": "POST, OPTIONS",
          "Access-Control-Allow-Headers": "*"
        }
      });
    }
    const url = new URL(request.url);
    const targetUrl = "https://api.openai.com" + url.pathname;
    const modifiedRequest = new Request(targetUrl, {
      method: request.method,
      headers: request.headers,
      body: request.body
    });
    const response = await fetch(modifiedRequest);
    const newHeaders = new Headers(response.headers);
    newHeaders.set("Access-Control-Allow-Origin", "*");
    return new Response(response.body, { status: response.status, headers: newHeaders });
  }
};
```

## 🛡️ Giới hạn đạo đức (Ethics & Safety)

Công cụ kế thừa tinh thần sáng tạo nhưng **tuyệt đối tuân thủ các nguyên tắc đạo đức**:
* Không khai thác thảm hoạ, cái chết, tai nạn hay tin tức đau thương.
* Không vật thể hoá hay hạ thấp phụ nữ (hoặc bất kỳ giới nào).
* Không gợi dục nhắm vào người thật, danh nhân, và tuyệt đối không liên quan đến trẻ vị thành niên.
* Với các sản phẩm tiêu dùng thông thường (ngoài ngành hàng người lớn): Giữ trọn kỹ thuật "ngữ nghĩa hai lớp", nhưng câu chữ luôn gắn chặt với **giá trị thật của sản phẩm**, tuyệt đối không biến tướng thành dung tục hay thô thiển.
